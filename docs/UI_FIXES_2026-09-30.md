# UI and pantry fixes — 2026-09-30

Implemented on ZPantry-Mobile develop, using the screenshots and these reports from the Frontend repository:
- https://github.com/ZPantry/ZPantry-Frontend/issues/1
- https://github.com/ZPantry/ZPantry-Frontend/issues/2
- https://github.com/ZPantry/ZPantry-Frontend/issues/3

## Changes
- Reserve layout space for bottom navigation, including the safe-area inset, so Profile logout remains reachable.
- Reduce action sizes; replace the inline expiry banner with a dismissible notification popup and a bell to reopen it.
- Keep web inputs and autofill consistent with the dark theme. OTP verification sends email and otpCode in the JSON body.
- Allow guide navigation forward, backward, directly to a step, or skipping without entering sample data.
- Add a quick-add chooser for manual, menu, text, and existing photo/receipt entry.
- Text entry uses POST /api/me/pantry/parse. Menu entry scales recipe ingredients by servings and combines matching units. Both require reviewing and explicitly confirming before saving.
- Preserve drafts on errors; validate quantities and dates; preserve freezer and pantry storage locations. Explain that saving an existing ingredient replaces its quantity.
