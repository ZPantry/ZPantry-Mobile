# Navigation and input UX — 2026-10-04

- Stack screens use `FixedBackHeader`, outside scrolling content. The back control remains in the top-left corner during scrolling, with safe-area padding. Inline duplicate back buttons are removed. The first survey uses “Để sau” to go directly to Home.
- Ingredient and quantity forms share `AppInput`: white background, readable dark text, stronger borders and orange focus. Browser styles no longer force these inputs transparent. Search fields also have clearer borders.
- Survey eligibility is created only after successful email registration verification. An account without this new-account marker goes directly to Home, including an existing account on a new device. The first survey display records its seen state, so a reload or later login does not repeat it. Preferences remain editable from Profile. This marker is stored separately from remembered login tokens. The current auth API provides no server-side new-account indicator for Google sign-in; it therefore follows the existing-account path.
- Old `interactive_guide` state is treated as complete. Home/Pantry guide banners and the automatic Add Ingredient tutorial are removed. The full guide remains accessible from Profile.
- A single global AI control is visible on regular signed-in screens. It measures 56×54, with a smaller 50×46 chef asset. Gesture Handler and Reanimated drive movement by transforms, with no React render on each drag frame. Dragging does not open chat; tapping does. Position is maintained while changing screens and clamped when the viewport changes. The browser’s native image drag is disabled. Native builds need the installed SDK 56 Gesture Handler dependency included in their next build.

Validation: TypeScript, Expo web export, 52 synthetic API/storage tests, and browser checks for fixed Back while scrolling, clear quantity inputs, first-visit survey/reload, drag versus tap, and existing API workflows. No Render data was changed. Device gesture feel and native safe areas still need verification on iOS/Android.
