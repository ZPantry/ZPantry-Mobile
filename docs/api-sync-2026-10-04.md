# Đối chiếu FE với Swagger — 04/10/2026

Nguồn: https://zpantry-java-backend.onrender.com/v3/api-docs (snapshot `work/openapi-live.json`). Đã đọc tài liệu Expo phiên bản https://docs.expo.dev/versions/v56.0.0/ trước khi sửa code.

| Nhóm API | Luồng FE và thay đổi |
| --- | --- |
| `/api/Auth/*` | Đăng ký, xác thực OTP, email/Google login, refresh, logout đã có. Bổ sung forgot-password và reset-password thành màn hình riêng, khóa gửi lặp, thời gian chờ gửi lại, xác nhận mật khẩu, giữ bản nhập khi lỗi. |
| `/api/me/profile/v2`, `/api/users/{userId}/profile` | Hồ sơ v2 là luồng chính; API hồ sơ cũ vẫn được giữ tương thích. Enum, ngày sinh và chỉ tiêu dinh dưỡng theo schema. |
| `/api/ingredients`, `/api/recipes` | Đọc toàn bộ trang danh mục ở khám phá. CRUD qua JSON và upload ảnh riêng để giữ mảng dị ứng, gồm cả thao tác xóa dị ứng bằng `[]`. Tên `protenPerUnit` ở create ingredient được giữ đúng contract Java. |
| `/api/v2/ingredients`, `/api/v2/recipes` | Contract multipart là phương án truyền dữ liệu thay thế; FE giữ helper FormData và đường dẫn v2. Luồng màn hình dùng JSON + media upload. |
| `/api/ingredients/{id}/aliases` | Bổ sung đọc/thêm/xóa tên gọi khác ở màn hình sửa nguyên liệu; xác nhận xóa, giữ tên nhập khi lỗi, kiểm tra tên trống/trùng/độ dài. |
| `/api/me/pantry`, `/api/me/pantry/items` | Đọc, thêm, sửa, xóa nguyên liệu trong tủ; API phân trang được tải đầy đủ. GET `/pantry/items` là phương án đọc thay thế cho GET `/pantry`. |
| `/api/me/pantry/parse`, `/api/me/pantry-import/*` | Văn bản, hóa đơn, ảnh và xác nhận nhập đã có; xác nhận vẫn tách riêng khỏi phân tích. Hiển thị cảnh báo cần kiểm tra và đơn vị nguồn. |
| `/api/v2/ingredients/analyze-image` | Bổ sung chế độ tự nhận diện. Chuyển `ingredients` sang danh sách kiểm tra FE; ảnh `UNKNOWN` không tạo dòng để lưu. Vẫn chọn được API hóa đơn/thực phẩm riêng. |
| `/api/recommendations/meals`, `/api/recommendations/v2/meals` | Giữ gợi ý thủ công và cá nhân hóa, bộ lọc theo schema. Ghép tên/ảnh từ danh mục nếu AI chỉ trả recipeId. Không điều hướng chi tiết bằng ID tự sinh. |
| `/api/recommendations/missing-ingredients` | Bổ sung gợi ý tên nguyên liệu cần mua từ chi tiết món. Request có `recipeId`, `recipeName`, `requiredIngredients`, `userIngredients`, theo schema AI trong repository local vì OpenAPI Java chỉ khai báo object. Cần xác minh lại contract này trên dịch vụ triển khai với đăng nhập thật. |
| `/api/recommendations/meals/{mealId}/missing-ingredients` | Giữ API kiểm tra khi có mã món đã lưu. Chi tiết công thức đối chiếu dữ liệu tủ/công thức thật ngay cả khi gợi ý không có mealId: cộng các dòng cùng nguyên liệu, quy đổi g/kg và ml/l, loại thực phẩm hết hạn, tính lượng thiếu theo khẩu phần. Đơn vị không rõ được cảnh báo. |
| `/api/recommendations/{id}`, `/{id}/feedback` | Bổ sung API client đọc lượt gợi ý và gửi phản hồi. Form đánh giá chỉ xuất hiện khi response có `recommendationId`/`mealRecommendationId` thật. Không dùng recipeId hoặc requestId của AI thay cho mã lượt gợi ý. GET record chưa có màn hình lịch sử riêng vì Swagger không cung cấp endpoint danh sách lượt gợi ý. |
| `/api/me/today-menu/*`, `/api/me/cooking-logs` | Lên lịch, chi tiết, xóa, hoàn thành và lịch sử đã có. Bổ sung chọn bữa, khẩu phần, ghi chú trong chi tiết công thức; hiển thị định lượng theo khẩu phần đã lưu; khóa thao tác khi hoàn thành đang chạy. |
| `/api/users/*`, `/api/admin/users/{id}/role` | Bổ sung đổi vai trò riêng với PATCH. Admin chỉ quản lý USER/MANAGER, Super Admin quản lý tất cả, Manager không quản lý người dùng. Hồ sơ/mật khẩu vẫn chỉ sửa cho chính chủ. Không cho đổi vai trò của chính mình từ form này để tránh quyền UI lỗi thời. |
| `/api/media/upload`, DELETE `/api/media` | Upload ảnh giữ luồng hiện có; bổ sung client xóa bằng publicId. Chưa đưa nút xóa media độc lập vào UI vì response ảnh danh mục chỉ là URL, không có publicId để thao tác; không suy diễn publicId từ URL. |

## Kiểm chứng

- TypeScript: `npm run typecheck`.
- API/unit tests: 50 trường hợp, có refresh token đồng thời, session race, phân trang, multipart, dị ứng, reset mật khẩu, phân quyền, aliases, unified image, khẩu phần và feedback.
- Web export: `npm run build`.
- Browser integration: `tests/swagger-flows.web.cjs`, dữ liệu giả lập. OTP sai rồi thử lại; đánh giá gợi ý; quy đổi lượng tủ và đổi khẩu phần; lưu thực đơn thất bại rồi thử lại; hoàn thành món với ảnh thất bại rồi thử lại và giữ ghi chú; phân quyền; aliases lỗi rồi thêm/xóa; nhận diện ảnh và chỉ lưu sau xác nhận. Tất cả đạt, không có lỗi runtime trình duyệt. Kiểm tra trên viewport điện thoại 390px và desktop 1280px. Chưa chạy trên thiết bị Android/iOS thật.
- Read-only Render: GET ingredients và recipes trả HTTP 200 với `totalItems: 0`; GET hồ sơ v2 không token trả HTTP 401. Danh mục thực tế đang rỗng nên chưa thể kiểm chứng luồng nấu ăn thực tế.

## Giới hạn cần lưu ý

Không có tài khoản kiểm thử được cung cấp cho backend triển khai nên chưa kiểm chứng gửi email OTP, Google OAuth, ghi dữ liệu, AI và upload ảnh thực tế. Các API generic object của recommendation không đủ schema để khẳng định parity response. Nếu backend không trả mã lượt gợi ý lưu trong response, chức năng feedback không thể tự nối vào luồng; FE đã chuẩn bị form và client nhưng không tự tạo mã.

Không gọi AI trực tiếp từ FE. Các tiện ích VIP, thiết bị và trung tâm thông báo chưa có API trong Swagger; giữ trạng thái chưa khả dụng hiện có. Không thay đổi backend hoặc tạo dữ liệu mẫu trên Render.
